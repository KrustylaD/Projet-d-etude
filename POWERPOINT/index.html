Défis techniques surmontés

⚠️ DÉFI 01
Cross-platform : 1 code, 2 plateformes
SOLUTION
Expo + détection Platform.OS pour les cas limites. AsyncStorage web vs SecureStore natif. Google Maps JS (web) vs react-native-maps (natif).
✅ iOS · Android · Web depuis 1 seul codebase
⚠️ DÉFI 02
Intégrer l'IA sans casser l'UX
SOLUTION
Streaming des réponses IA pour éviter les temps de chargement bloquants. Parsing automatique des réponses structurées pour mise à jour du dossier.
✅ Expérience fluide — diagnostic en < 5 secondes
⚠️ DÉFI 03
Sécuriser les données sans backend custom
SOLUTION
SecureStore (natif) + AsyncStorage (web). Tokens JWT gérés côté FastAPI. Architecture Emergent pour l'isolation des environnements.
✅ Auth sécurisée · Données isolées par utilisateur
